# Хроники золотого дракона

Пиксельная RPG в браузере: открытый мир, подземелья, башня лича, арена, ремёсла и сюжет с выбором ответов.

**Играть:** https://alexzoriks.github.io/Dragon-play/

На телефоне: откройте ссылку в Safari (iPhone) или Chrome (Android) → «Поделиться» → «На экран „Домой“» — игра установится как приложение и будет запускаться без адресной строки.
